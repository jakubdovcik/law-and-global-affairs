# materials/

Drop course files here: reading PDFs, slides, handouts, anything from the course website.
Upload on github.com with **Add file → Upload files**, or `git add` locally.

Suggested names: `t02-lotus.pdf`, `t04-cohen-property-sovereignty.pdf` (topic number + reading id). Any name is fine though.

Then ask Claude to process them. It reads each file and fills in `data/course.json`: summary, key arguments, concepts, connections. It also extends `data/guide.md`.

Lecture notes can go in `notes/` (or be written in the app under [n]otes).
